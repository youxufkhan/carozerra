These WOFF2 fonts are Latin subsets of IBM Plex Sans Regular and SemiBold,
from Debian's fonts-ibm-plex package. They retain the original glyph designs.
The modified fonts' internal family names are Carozerra Sans to respect the
reserved font name. CSS uses IBM Plex Sans as the local presentation alias.
